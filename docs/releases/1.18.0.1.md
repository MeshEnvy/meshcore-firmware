# MeshCore 1.18.0.1 - USA Cascade

**Stable release.** Meshtext chat, simpler ESP32 administration and new repeater
controls. Changes below are relative to **1.17.1.9**.

[See all features beyond mainline MeshCore](#extra-features) | [Choose your firmware](../firmware_picker.md) | [Update instructions](../ota_user_guide.md)

## New

- **Meshtext chat on supported Full Companions**, including T1000-E.
  Use channels such as `#mt-longfast`; see [Meshtext setup](../radio_profiles.md#meshtext-channel-chat).
- **WiFi repeater bridge:** connect up to eight peers by IP on an existing
  network. [WiFi setup](../udp_bridge_setup.md).
  [ESP-NOW](../espnow_bridge_setup.md) and [RS232](../rs232_bridge_setup.md)
  also gain status, counters and link tests.
- **One ESP32 admin password** for device setup, browser administration and
  WiFi firmware uploads. Router WiFi passwords and Bluetooth PINs stay separate.
  [Password details](../WiFi.md)
- **Telemetry choices:** turn individual packet types on or off. All types
  are selected by default; sending telemetry still requires enabling it.
  [Telemetry controls](../cli_commands.md#read-repeater-telemetry-history)
- **Low-battery forwarding limits:** optionally stop repeating below 10% and
  flooding below 20%, or set your own thresholds. Both limits default off.
  [Battery controls](../cli_commands.md#pause-forwarding-when-the-battery-is-low)
- **Radio2 setup warns about overlapping channels** and suggests a clearer
  center frequency. [Channel spacing](../radio_profiles.md#channel-spacing).
  Supported boards also gain [faster switching and saved tuning controls](../radio_profiles.md#saved-switching-controls).
- **T114 automatic screen detection:** one image for boards with or without
  the supported display.
- **Optional nRF52 bootloader update included** in supported Repeater and
  Room Server images. These carry the exact board's OTAFIX 2.4.12 bootloader.
  [Installation requirements](../nrf52_embedded_bootloader.md#install-and-activate)

## Fixed

- G3 startup and radio pin/slot handling.
- XIAO nRF52 external-flash startup, storage alignment and Bluetooth handling.
- V4 USB logging idle/reopen failures and ESP32 Bluetooth/power-saving recovery.

## Before updating

- Match the exact board and storage layout. ESP32 USB installs use a merged
  image; WiFi updates use an app-only image and a compatible partition layout.
  [Update guide](../ota_user_guide.md)
- An included nRF52 bootloader checks for a compatible older version after
  70 seconds. It is not a recovery tool for an unrecognized bootloader.
  [Bootloader guide](../nrf52_embedded_bootloader.md)
- Fresh USA Cascade radio defaults: **910.525 MHz / BW62.5 / SF7 / CR5**.
  Existing saved radio settings take precedence.

## Tested and limitations

The complete release passed build, memory and package checks, and
[release-source CI](https://github.com/mikecarper/MeshCore/actions/runs/40101490838).
[Hardware reports](../test-results/index.md) cover USB, Bluetooth, contact sync,
LoRa and updates at the revisions recorded. The final build has not been
physically tested on every board.

- **T1000-E:** Bluetooth pauses while connected to a USB data host and resumes
  after unplugging if enabled. Bluetooth works on battery or a charge-only supply.
- **Radio2:** two profiles share one radio; simultaneous reception is not guaranteed.
- **Morse receive:** noise can still produce false letters.
